# Recursos

El curso **enseña dentro de sus propios archivos**: no es una colección de enlaces. Esta carpeta guarda lo que sirve de apoyo.

| Archivo | Contenido |
|---|---|
| [VERSIONES.md](VERSIONES.md) | Versiones fijadas del curso, cómo se comprobaron y qué **no** se pudo comprobar. |
| [ENLACES.md](ENLACES.md) | Estado real de verificación de cada enlace externo. |
| [enlaces-verificados.json](enlaces-verificados.json) | Datos de verificación que alimentan la tabla anterior. |

## Fuentes que se priorizan

1. **Documentación oficial**: Microsoft Learn (C#, .NET, ASP.NET Core, EF Core, SQL Server), documentación de Git y de GitHub.
2. **Tutoriales oficiales** del fabricante (por ejemplo, el *Tour de C#*): útiles como segunda explicación, pero **no sustituyen** los retos.
3. **Libros** de reconocida calidad (por ejemplo, *Pro Git*): se marcan expresamente.
4. **Opiniones y blogs**: solo como contexto y siempre marcados como tales.

## Cómo usar un recurso sin copiarlo

Lees → cierras → explicas con tus palabras → escribes tu propio ejemplo. Si no puedes hacerlo sin mirar, no lo has aprendido todavía.
