# Errores recurrentes

Aquí se anotan los errores que aparecen **dos o más veces**. Revisarlo antes de cada evaluación y de cada puerta.

**Cómo usar este archivo**

1. Cuando un error se repite, se añade una fila (o se incrementa el contador).
2. En *Causa probable* se escribe por qué ocurre (concepto mal entendido, descuido, hábito), no solo qué pasó.
3. En *Ejercicio de refuerzo* se enlaza un reto específico. Cuando se supera sin ayuda tres veces seguidas, el error pasa a *Superados*.
