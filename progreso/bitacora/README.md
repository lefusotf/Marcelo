# Bitácora de sesiones

Un archivo por sesión con el nombre `AAAA-MM-DD_sesion-NN.md`. Se crea al **cerrar** la sesión usando la plantilla [plantillas/bitacora-de-sesion.md](../../plantillas/bitacora-de-sesion.md).

Una sesión que no tiene bitácora con el cierre de 5 puntos **no cuenta**.

Qué no se hace aquí: pegar el código de la lección. La bitácora registra *qué pasó*: qué estudiaste, qué resolviste solo, qué errores cometiste, qué ayuda usaste y qué sigue.
