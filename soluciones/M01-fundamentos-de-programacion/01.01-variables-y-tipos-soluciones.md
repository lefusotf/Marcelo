## R-1.1-N1-A · Elegir el tipo

| N.º | Dato | Tipo | Justificación |
|---|---|---|---|
| 1 | Edad | `int` | Entero pequeño. |
| 2 | Precio de un producto | `decimal` | Es dinero: la base 10 evita errores de representación. |
| 3 | Teléfono | **`string`** | No se hacen cálculos con él; puede empezar con ceros o llevar `+` y guiones; un `int` no lo sostiene. |
| 4 | Temperatura corporal | `double` | Una medición con decimales; un error mínimo de precisión no importa. |
| 5 | Población mundial | **`long`** | ≈ 8,1 × 10⁹ supera el máximo de `int` (≈ 2,1 × 10⁹). |
| 6 | ¿Es mayor de edad? | `bool` | Sí o no. |
| 7 | Inicial del nombre | `char` | Un solo carácter. |
| 8 | Nombre completo | `string` | Texto. |
| 9 | Saldo bancario | **`decimal`** | Dinero: exactitud. |
| 10 | Código `A-1023` | **`string`** | Contiene letras y guion; es un identificador, no una cantidad. |
| 11 | Estudiantes de un aula | `int` | Conteo pequeño. |
| 12 | Promedio de notas | `double` (también válido `decimal`) | Decimales; si el requisito exige exactitud en las décimas, `decimal`. Lo importante es justificarlo. |

**Regla para recordar:** *¿Voy a hacer cuentas con él?* Si no, probablemente es un `string` (aunque parezca un número).

## R-1.1-N1-C · Errores de declaración

| N.º | Problema | Corrección | Código |
|---|---|---|---|
| 1 | Se guarda un texto en un `int`. | `string edad = "veinte";` o `int edad = 20;` | `CS0029` |
| 2 | `double` → `int` pierde la parte decimal; el compilador exige que lo pidas. | `(int)altura`, o declarar `alturaEntera` como `double`. | `CS0266` |
| 3 | `9.99` es `double`; falta el sufijo de `decimal`. | `9.99m` | `CS0664` |
| 4 | La variable no tiene valor antes de leerla. | `int x = 0;` | `CS0165` |
| 5 | Una constante no se puede reasignar. | Usar una variable si debe cambiar. | `CS0131` |
| 6 | El nombre `a` ya existe en este ámbito. | `a = 2;` (asignar, no declarar). | `CS0128` |

<!--v
modo: error CS0029
-->
```csharp
int edad = "veinte";
```

<!--v
modo: error CS0266
-->
```csharp

```

<!--v
modo: error CS0664
-->
```csharp

```

<!--v

## R-1.1-N1-D · Intercambio de variables

<!--v
modo: ejecuta
salida: siguiente
-->
```csharp
int a = 3;
int b = 8;
int temp = a;
a = b;
b = temp;
Console.WriteLine($"a={a}, b={b}");
```

```text
a=8, b=3
```

| Tras la línea | `a` | `b` | `temp` |
|---|---|---|---|
| `int a = 3;` | 3 | — | — |
| `int b = 8;` | 3 | 8 | — |
| `int temp = a;` | 3 | 8 | 3 |
| `a = b;` | 8 | 8 | 3 |
| `b = temp;` | 8 | 3 | 3 |

**Sin `temp`:**

<!--v
modo: ejecuta
salida: siguiente
-->
```csharp
int a = 3;
int b = 8;
a = b;
b = a;
Console.WriteLine($"a={a}, b={b}");
```

```text
a=8, b=8
```

Tras `a = b;`, el valor original de `a` (3) **se sobrescribe y se pierde**; `b = a;` copia el 8 nuevo. **Analogía:** para intercambiar el contenido de dos vasos con líquidos distintos necesitas un tercer vaso vacío.

## R-1.1-N3-B · Tabla de límites

<!--v

```csharp
Console.WriteLine($"int mínimo: {int.MinValue}");
Console.WriteLine($"int máximo: {int.MaxValue}");
Console.WriteLine($"long mínimo: {long.MinValue}");
Console.WriteLine($"long máximo: {long.MaxValue}");

int minimo = int.MinValue;
minimo = minimo - 1;

```

```text
int mínimo: -2147483648
int máximo: 2147483647
long mínimo: -9223372036854775808
long máximo: 9223372036854775807
int máximo + 1 = -2147483648
int mínimo - 1 = 2147483647
long (máximo de int) + 1 = 2147483648
```

**Caso límite: ¿por qué `int x = int.MaxValue + 1;` no compila?**

<!--v
modo: error CS0220
-->
```csharp
int x = int.MaxValue + 1;
```

`CS0220`: el compilador evalúa **expresiones constantes** en tiempo de compilación y detecta el desbordamiento. Con **variables**, el valor se conoce al ejecutar, y por defecto C# no comprueba el desbordamiento: da la vuelta en silencio. Esa diferencia es la que hace el desbordamiento peligroso.

## R-1.1-N4-A · Nómina con tipos mal elegidos

**Estado 0 · programa original.** No compila. Los errores de tipos aparecen **juntos** (los tres):

<!--v
modo: error CS0266
-->
```csharp
int salarioBase = 1250.00;
int horasExtra = 8;
double tarifaExtra = 7.50;
decimal porcentajeDescuento = 9;
string meses = "12";

decimal pagoExtra = horasExtra * tarifaExtra;
decimal bruto = salarioBase + pagoExtra;
decimal descuento = bruto * porcentajeDescuento;
decimal neto = bruto - descuento;
decimal anual = neto * meses;

Console.WriteLine("Pago por horas extra: " + pagoExtra);
Console.WriteLine("Salario bruto: " + bruto);
Console.WriteLine("Descuento: " + descuento);
Console.WriteLine("Salario neto: " + neto);
Console.WriteLine("Neto anual: " + anual);
```

Mensajes (SDK 10):

```text
Program.cs(1,19): error CS0266: Cannot implicitly convert type 'double' to 'int'. An explicit conversion exists (are you missing a cast?)
Program.cs(7,21): error CS0266: Cannot implicitly convert type 'double' to 'decimal'. An explicit conversion exists (are you missing a cast?)
Program.cs(11,17): error CS0019: Operator '*' cannot be applied to operands of type 'decimal' and 'string'
```

| N.º | Línea | Error | Causa | Corrección |
|---|---|---|---|---|
| 1 | 1 | `CS0266` | `1250.00` es `double` y se guarda en un `int`: el salario es dinero. | `decimal salarioBase = 1250.00m;` |
| 2 | 7 | `CS0266` | `horasExtra * tarifaExtra` es `int × double` = `double`, no se guarda en `decimal`. La tarifa es dinero y debe ser `decimal`. | `decimal tarifaExtra = 7.50m;` |
| 3 | 11 | `CS0019` | `decimal × string`: los meses están como texto. | `const int MesesDelAnio = 12;` y usar ese nombre. |

**Un parche tentador (y malo):** `(decimal)tarifaExtra`. Compila, pero el valor viaja como `double` (aproximado) y se convierte; con tarifas como `0.1` el error de binario ya está dentro. Se corrige **eligiendo bien el tipo desde la declaración**.

**Estado 1 · tras corregir los tres errores de compilación.** Compila y corre, pero muestra datos absurdos:

```csharp
decimal salarioBase = 0.00m;
int horasExtra = 10;
decimal tarifaExtra = 7.50m;
decimal porcentajeDescuento = 0.09m;
const int MesesDelAnio = 12;

decimal pagoExtra = horasExtra * tarifaExtra;
decimal bruto = salarioBase + pagoExtra;
decimal descuento = bruto * porcentajeDescuento;
decimal neto = bruto - descuento;
decimal anual = neto * MesesDelAnio;

Console.WriteLine($"Pago por horas extra: {pagoExtra:F2}");
Console.WriteLine($"Salario bruto: {bruto:F2}");
Console.WriteLine($"Descuento: {descuento:F2}");
Console.WriteLine($"Salario neto: {neto:F2}");
Console.WriteLine($"Neto anual: {anual:F2}");
```
