# Módulo 2 · Lógica y resolución de problemas

> **Semanas:** 5–6 · **Fase:** A · Fundamentos · [Plan de estudio](../../PLAN_DE_ESTUDIO.md) · [Índice](../../INDICE.md) · [Calendario](../../CALENDARIO.md)

## Objetivo

Aprender a pensar antes de programar: descomponer un problema, definir entradas/proceso/salidas, diseñar un algoritmo, probar casos límite y reconocer los patrones de siempre (contar, acumular, buscar, clasificar).

## Por qué importa

Programar bien es, sobre todo, resolver bien. Este módulo es el que separa a quien sabe sintaxis de quien resuelve problemas. También prepara el terreno para las entrevistas técnicas.

## Requisitos previos

Módulo 1 dominado (bucles, condicionales, métodos, arrays/listas y cadenas).

## Competencias de salida

Estas competencias se registran en [progreso/competencias.md](../../progreso/competencias.md) y solo se marcan como *demostradas* con evidencia (programa, evaluación o defensa).

## Cómo se trabaja este módulo

Casi todo se hace primero en papel (pseudocódigo, trazas) y después en código. Se compara más de una solución. Hay una **prueba acumulativa sin apuntes ni IA** en la semana 6.

## Errores típicos de este módulo

Programar sin plan · no probar los casos límite (vacío, uno, repetidos, negativos) · confundir "funciona con mi ejemplo" con "es correcto" · no poder explicar la solución.
