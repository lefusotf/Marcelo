# Módulo 10 · Proyectos integradores

> **Semanas:** 4, 9, 17, 20, 23, 24–26 · **Fase:** Transversal · [Plan de estudio](../../PLAN_DE_ESTUDIO.md) · [Índice](../../INDICE.md) · [Calendario](../../CALENDARIO.md)

## Objetivo

Integrar todo lo aprendido en seis proyectos de dificultad creciente que acaban en un proyecto final original para el portafolio.

## Por qué importa

El portafolio es la evidencia que verá quien te entreviste. Cada proyecto se planifica, se construye en iteraciones pequeñas, se prueba, se documenta y se defiende oralmente.

## Requisitos previos

Los módulos que alimentan cada proyecto (ver la tabla de proyectos).

## Competencias de salida

Estas competencias se registran en [progreso/competencias.md](../../progreso/competencias.md) y solo se marcan como *demostradas* con evidencia (programa, evaluación o defensa).

| Código | Al terminar el módulo… |
|---|---|
| M10-C1 | Planifico un proyecto: requisitos, diseño, tareas pequeñas y criterios de aceptación. |
| M10-C2 | Implemento por iteraciones, probando y versionando cada avance. |
| M10-C3 | Documento el proyecto con un README que otra persona puede seguir. |
| M10-C4 | Defiendo mis decisiones técnicas y los problemas que resolví. |

## Cómo se trabaja este módulo

No se construyen los proyectos por ti: se guían por etapas y tú implementas las partes centrales. El proyecto final (P6) es **tuyo**: tema original, decisiones propias.

## Errores típicos de este módulo

Alcance desbordado · empezar a programar sin requisitos · pruebas al final · README tardío · credenciales en el repositorio · no poder explicar partes del propio proyecto.

## Evaluación y puerta de avance

Cada proyecto se evalúa con la **rúbrica D** (requisitos, diseño, calidad, pruebas, documentación y defensa). Bloqueantes: credenciales en el repositorio, proyecto que no se ejecuta, no poder explicar tu código.

Criterios y reglas esenciales: [evaluaciones/RUBRICAS.md](../../evaluaciones/RUBRICAS.md). Puertas: [PLAN_DE_ESTUDIO.md, sección 5](../../PLAN_DE_ESTUDIO.md#5-puertas-de-avance).
