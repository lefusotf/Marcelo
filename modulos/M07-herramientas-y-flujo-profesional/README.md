# Módulo 7 · Herramientas y flujo de trabajo profesional

> **Semanas:** 17–18 · **Fase:** D · Oficio profesional · [Plan de estudio](../../PLAN_DE_ESTUDIO.md) · [Índice](../../INDICE.md) · [Calendario](../../CALENDARIO.md)

## Objetivo

Trabajar como se trabaja en equipo: Git con ramas y conflictos, GitHub con issues y pull requests, convenciones y formato, depuración avanzada, revisión de código ajeno y documentación útil.

## Por qué importa

Un portafolio sin historial de Git cuidado y sin README no convence. Y revisar código ajeno es el 50 % del trabajo de un junior.

## Requisitos previos

Módulo 6 en curso (P3 terminado). Git mínimo del módulo 0.

## Cómo se trabaja este módulo

Se trabaja sobre tus propios proyectos: ramas y PR en P3 y P4. Se practica el flujo completo: tarea → rama → commits → PR → revisión → fusión.

## Errores típicos de este módulo

Commits enormes · mensajes vagos · trabajar en la rama principal · resolver conflictos sin entender · revisar solo estilo · README sin instrucciones de ejecución.

## Proyecto asociado

Sin proyecto propio; un PR real sobre tu propio repositorio es criterio de la puerta.
