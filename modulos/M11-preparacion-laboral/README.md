# Módulo 11 · Preparación para el mundo laboral

> **Semanas:** 24–28 · **Fase:** E · Web y portafolio · [Plan de estudio](../../PLAN_DE_ESTUDIO.md) · [Índice](../../INDICE.md) · [Calendario](../../CALENDARIO.md)

## Objetivo

Convertir lo aprendido en candidaturas creíbles: leer ofertas, preparar un CV y un GitHub honestos, defender decisiones técnicas, practicar entrevistas y pruebas con tiempo limitado, y planificar lo siguiente.

## Por qué importa

Saber programar no basta: hay que demostrarlo con honestidad y claridad. Este módulo cierra la brecha entre "hice proyectos" y "me pueden contratar para un puesto junior o prácticas".

## Requisitos previos

Al menos P3 terminado; idealmente P5 y P6 en marcha.

## Competencias de salida

Estas competencias se registran en [progreso/competencias.md](../../progreso/competencias.md) y solo se marcan como *demostradas* con evidencia (programa, evaluación o defensa).

| Código | Al terminar el módulo… |
|---|---|
| M11-C1 | Leo ofertas laborales y contrasto sus requisitos con mis competencias reales. |
| M11-C2 | Preparo un CV y un GitHub honestos y coherentes entre sí. |
| M11-C3 | Explico y defiendo decisiones técnicas de mis proyectos. |
| M11-C4 | Resuelvo ejercicios técnicos con tiempo limitado y respondo preguntas frecuentes. |
| M11-C5 | Identifico mis lagunas y planifico qué estudiar a continuación. |

## Cómo se trabaja este módulo

Las tareas laborales se reparten a lo largo de la ruta (borrador de CV en la semana 12; perfil de GitHub desde la semana 17) y se intensifican al final. Todo debe ser **verificable y honesto**: se declara lo que dominas y lo que no.

## Errores típicos de este módulo

Inflar el CV · listar tecnologías no dominadas · repositorios sin README · no saber explicar los propios proyectos · enviar candidaturas sin leer la oferta.

## Proyecto asociado

Se apoya en P6 (proyecto final) y en el portafolio de GitHub.

## Evaluación y puerta de avance

Simulacros de entrevista, pruebas técnicas con tiempo y **evaluación final** (semana 28). **Puerta final** en la semana 26.

Criterios y reglas esenciales: [evaluaciones/RUBRICAS.md](../../evaluaciones/RUBRICAS.md). Puertas: [PLAN_DE_ESTUDIO.md, sección 5](../../PLAN_DE_ESTUDIO.md#5-puertas-de-avance).
